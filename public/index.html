ПРО СИСТЕМУ

MasterHub

MasterHub — навчальна система керування замовленнями для маркетплейсу перевірених майстрів. Клієнт створює замовлення, майстер або адміністратор опрацьовує його, а всі зміни проходять через API та обране сховище.

FrontendНативний responsive SPA без важких залежностей
BackendNode.js, Express, PostgreSQL або SQLite fallback
БезпекаРолі, scrypt-паролі та HttpOnly-сесії
